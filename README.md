## 🚀 Using the Application
Once you launch the app, follow this workflow to start your first session.

### Initial Configuration
When you open tacit-mining for the first time, the settings window appears. Enter your Claude API key in the provided field. This key allows the software to connect with the AI engine. You receive this key from your account dashboard on the Claude developer website. 

### Starting a Dialogue
Select the Start New Session button on the main dashboard. Choose a topic you want to explore. The application presents a list of suggested areas, such as project history, problem solving steps, or deep technical procedures. Pick a category that matches your goals.

### The Interview Process
The application initiates a conversation in the chat box. Read the questions carefully. Type your answers as notes or rough thoughts. You do not need to write formal sentences. The AI interprets your shorthand and asks follow-up questions to refine the output. If you run out of things to say, click the Suggest Path button to receive a new prompt.

### Saving Your Gains
After you finish the discussion, click the Export button. The application organizes your answers into a clean text file or a structured document. You can save this file anywhere on your computer for future use.

## ⚙️ Understanding the Features
The software focuses on a few core functions to maintain speed and reliability.

### Structured Dialogue
The app builds a map of your knowledge. It tracks concepts and links them together. This prevents you from repeating information and ensures the chat stays on track.

### Knowledge Extraction
The internal engine identifies key patterns in your text. It filters out filler words to focus on the core logic of your work processes.

### Privacy and Local Control
Your data stays on your machine during the initial draft phase. The application only sends text segments to the AI service to gain understanding. You retain control over which parts of your knowledge you wish to process.

## 🛠 Troubleshooting
If you experience issues, consult this guide for common solutions.

### The App Does Not Launch
Confirm that your Windows version meets the requirements. If the app fails to open, check if your antivirus software blocked the installation. Sometimes, security settings flag new software. Create an exception for the tacit-mining folder in your security settings.

### AI Connection Fails
Ensure your internet connection is active. Check your API key in the settings menu. If you copied the key, ensure there are no extra spaces at the beginning or end of the string. A depleted credit balance on your API account also causes this error.

### Low Quality Answers
If the output lacks detail, change your input method. Provide specific examples instead of general statements. Tell the AI about a time you solved a specific problem. Concrete details help the AI create better summaries.
